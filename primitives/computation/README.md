# Computation functions

A computation function runs specified code or expressions to calculate or transform data. It has declared inputs and outputs and can be called by an agent or used by a workflow. It need not be mathematically pure. AI-assisted authoring may help write the logic; a run executes the defined operation.

Planned; this directory contains a design note, not an implemented runtime adapter. See [Functions and availability](../../docs/concepts/functions.md#availability) and [Brain terminology](../../docs/concepts/terminology.md).
