# Recall functions

A recall function retrieves or reconstructs relevant information from configured sources. Those sources may include the event ledger, documents or other connected information. A projection derives a view from event history; it is one possible recall mechanism. Memory describes the broader retention and availability of information.

Planned; this directory contains a design note, not an implemented runtime adapter. The directory keeps its existing name, `recollection`; the product category is Recall and its reusable resource is a recall function. See [Functions and availability](../../docs/concepts/functions.md#availability) and [Brain terminology](../../docs/concepts/terminology.md).
