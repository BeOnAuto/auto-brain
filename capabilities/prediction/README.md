# Prediction functions

A prediction function defines a predictive capability, including creating an ML model and using it to make predictions. Keep the reusable function, its predictive model and the prediction returned by a run distinct. The intended lifecycle permits an initial call to build a model and later calls to use it.

Planned; this directory contains a design note, not a model-training implementation. Build model, Evaluate model, Predict and Retrain model are names for lifecycle controls when supported. See [Functions and availability](../../docs/concepts/functions.md#availability) and [Brain terminology](../../docs/concepts/terminology.md).
